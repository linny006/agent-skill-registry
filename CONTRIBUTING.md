# Contributing to Agent Skill Registry

Thanks for considering a contribution! This list aims to stay high-signal
and useful — the bar for new entries is "would a working developer in this
space actually open this link?"

## Adding an entry

1. Open a pull request that adds your entry to the most relevant section.
2. Use this format:

   ```
   - [Name](https://link) — One short sentence on what it does and why it
     belongs here.
   ```

3. Keep the description specific. "Fast" or "easy to use" without context
   is not useful — explain *what tradeoff* the project makes.
4. Alphabetize within each section unless the section uses a different
   convention noted at the top.

## What gets rejected

- Dead links (the link-check action will flag these on PR).
- Marketing copy without substance.
- Projects with zero recent activity (> 12 months since last commit).
- Anything that significantly overlaps an existing entry without adding a
  distinct angle.

## Adding a new section

Open an issue first to discuss the section's scope. Sections should have
at least 3 plausible entries to be worth adding.
